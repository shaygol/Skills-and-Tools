# Skills-and-Tools

Claude skills and small tools.

## Skills

| Skill | What it does |
|---|---|
| [job-kit](job-kit/) | Job applications: build a resume tailored to a posting, review a resume with a scored reviewer panel, and prepare the application (cover letter, tailoring note, interview and offer prep). Adapts per domain profile. |

## Using a skill

Each skill lives in its own folder with a `SKILL.md` and a README. Copy or symlink the folder into your skills directory (for Claude Code, `~/.claude/skills/<skill>/`), or upload it as a skill in Claude. Personal settings go in a config file outside this repository; see each skill's README.
